# ⚡ Aethon Fit

A Greek Hero-themed Progressive Web App (PWA) designed to bring discipline, strength training, and structured tracking to your daily fitness routine. Inspired by Heracles.

## 🚀 Features
- **Greek Hero Aesthetics:** Dark-themed UI styled with custom M3 design principles, custom emblems, and motivational quotes.
- **Workout & Fitness Tracker:** Structured routines and progress tracking.
- **Offline Support:** Powered by a background service worker (`sw.js`) for seamless offline performance.
- **Installable PWA:** Can be installed directly on Android devices as a native application.

## 🛠️ Tech Stack
- HTML5 / Vanilla JavaScript (`script.js`)
- Tailwind CSS & Custom CSS (`styles.css`)
- Web App Manifest (`manifest.json`) & Service Worker (`sw.js`)
